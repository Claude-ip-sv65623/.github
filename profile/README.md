<p>选型这件事，很多人是在下单那一刻才开始想，其实真正的时间轴应该从下单前一周就启动：先问清逻辑，再用小样验证，然后分阶段放量，最后在第三个月回头复盘一次组合是否还合适。每个阶段的目标不同，能下结论的时点也不同，把节奏踩对了，就不会出现「用了一个月才发现选错」的情况。下面按时间顺序把六个节点排开，给出每个节点该看什么、能得出什么结论。</p>
<h2>一、时间轴的起点：下单前一周</h2>
<p>这一周不做技术验证，只做逻辑梳理。逻辑不清，后面所有测试都是在错误的方向上收集数据。</p>
<h3>先写清自己的三个约束</h3>
<p>预算上限、号码规模、业务高峰时段。三个约束决定了你该选共享池、静态住宅还是机房独享。预算紧而规模大，硬上静态住宅会导致中途降级，反而更乱。</p>
<h3>再把「必须项」和「加分项」分开</h3>
<p>必须项比如「地址一个月不变」「归属为住宅运营商」；加分项比如「支持按小时计费」「提供接口开通」。必须项不满足直接排除，加分项按预算取舍。混在一起比价，永远比不出结果。</p>
<h2>二、下单前三天：把该问的问完</h2>
<p>三天时间够问清五件事，也够要到一份书面说明。别嫌麻烦，这几句话能省掉后面一个月的弯路。</p>
<h3>问资源，不问承诺</h3>
<p>「这条线现在几个用户」比「我们保证独享」有用。要具体数字和分配方式，回答含糊的按共享处理。再问一句「地址在什么情况下会变」，把「偶尔」换成频率。</p>
<h3>问故障处理，不问 uptime</h3>
<p>99% 的可用性承诺意义有限，因为剩下 1% 可能正好落在你的扣费日。更有价值的信息是：故障时段谁能响应、换线要不要重配环境、历史平均恢复时间是多少。</p>

<h2>三、试用第一周：三个阶段看不同表现</h2>
<p>一周试用要拆成三段，每段有独立的观察目标，否则一周下来只有一句「感觉还行」。</p>
<h3>前两天的连通与归属</h3>
<p>核 ASN、反解域名、出口城市，三项对齐后记录进台账。这两天不做业务，只做静态核验。核验不通过的，直接结束试用，不用进入下一段。</p>
<h3>第三到五天的并发与稳定性</h3>
<p>每天固定两个时段登录，中间插一次并发测试：同时开三个号跑同类任务。观察是否互相挤、延迟涨幅多少。涨幅在 50% 以内算正常，超过说明带宽被分。</p>
<h3>第六到七天的持续挂机</h3>
<p>挂满四十八小时，每十分钟记一次延迟。重点看夜间是否有规律性断连，以及恢复后地址有没有变。这两天暴露的问题，通常就是长期使用中最常见的问题。</p>
<h2>四、第一个月：从小样到多号的过渡</h2>
<p>单号稳定不代表多号稳定。第一个月的核心任务是把「一个人的经验」变成「一批号的可复制流程」。</p>
<h3>先做三套模板</h3>
<p>环境模板、出口模板、任务模板。三套模板固化下来，新号开通就是从模板复制，不再靠手工填。这一步做完，扩量的边际成本会明显下降。</p>
<h3>再分两批加号</h3>
<p>第一批加到十号，观察一周；第二批加到三十号，再观察一周。每批保留前一批的两三个号不动，作为对照。对照组的表现在这个阶段是最有价值的判断依据。</p>

<h3>一个月内别换组合</h3>
<p>换组合等于换掉所有变量，前面积累的数据全部作废。真有问题，先在原组合内换线，而不是换类型。类型层面的决策留到第三个月复盘时再做。</p>
<h2>五、第三个月：复盘一次组合是否还合适</h2>
<p>三个月是业务形态容易发生变化的节点，也是重新评估的最佳时点。最初的约束可能已经变了。</p>
<h3>看三个变化</h3>
<p>号量是否翻倍、业务高峰是否转移、单号平均在线时长是否拉长。任何一项变化明显，原来的组合就可能不再是最优。比如在线时长从每天两小时拉到八小时，按量计费就会变贵。</p>
<h3>换与不换的判断线</h3>
<p>成本上涨超过三成、或者一个月内出现三次以上同类故障，才考虑换类型。只是价格略高、偶发一次异常，优先在原供应商内调整规格，迁移的隐性成本通常更高。</p>

<h2>常见问答</h2>
<h3>一定要试满一周吗？</h3>
<p>答：建议试满。三天能看出归属和基本连通，但夜间的规律性断连、周末的表现差异，都需要时间才能暴露。赶时间的可以压到五天，别压到两天。</p>
<h3>第一个月加到多少号算合理？</h3>
<p>答：从单号加到三十号左右是比较稳的节奏。再往上就需要分组、备用线和调度机制，属于另一个阶段的事，硬加容易出连带问题。</p>
<h3>第三个月复盘发现成本涨了，先换还是先谈？</h3>
<p>答：先谈。用三个月的用量数据去谈长约或规格调整，通常能拿到比新客更好的条件。谈不下来再考虑换，因为迁移成本是实打实的。</p>
<h3>台账谁来记？</h3>
<p>答：谁处理谁记，不设专职。事件发生后顺手写一行，比事后回忆补全更准。每周由一个人汇总一次，确保没有遗漏。</p>
